GF STUDIO - GITHUB PAGES

1. Create a PUBLIC repository named GFGAMES6.github.io under GFGAMES6.
2. Upload index.html, styles.css, script.js, .nojekyll and (optionally) this README into the repository root.
3. Settings > Pages > Deploy from a branch > main > /(root) > Save.
4. Check https://gfgames6.github.io/ once deployed.
5. Existing Neon Shift privacy policy remains at https://gfgames6.github.io/-neon-shift-privacy/ (provided GitHub Pages is enabled for that repository).
6. To configure app-ads.txt, get the real AdMob publisher ID from AdMob > Settings > Account information. Rename app-ads.EXAMPLE.txt to app-ads.txt, replace placeholder ID, and upload to root. Never publish placeholder.
7. Add https://gfgames6.github.io/ to Google Play developer website field. Google AdMob may not accept a github.io shared subdomain for app-ads.txt; if verification fails, use a custom domain you control.
